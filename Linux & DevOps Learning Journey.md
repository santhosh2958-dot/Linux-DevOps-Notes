1. Learn one new concept.
2. Understand the command and its important options.
3. Practice on my Ubuntu system or an AWS EC2 Linux instance.
4. Record the syntax and expected output.
5. Understand what the output means.
6. Document errors and troubleshooting steps.
7. Add the notes to the appropriate GitHub folder.
8. Revise previously learned commands.
9. Practice related interview questions.
10. Build a small project using the concept.

## 📝 Notes Format

Every topic should include the following wherever applicable:

- **Definition:** What is it?
- **Purpose:** Why is it used?
- **Syntax:** How do I use it?
- **Options:** Important command flags and their meanings.
- **Examples:** Basic, intermediate, and advanced usage.
- **Expected Output:** How to verify the result.
- **Practical Exercise:** Hands-on tasks on Ubuntu or AWS EC2.
- **Troubleshooting:** Common errors and their solutions.
- **Real-World Use:** How it helps in Linux administration or DevOps.
- **Interview Questions:** Questions with clear answers.
- **Quick Revision:** Important points to remember.

## 🔐 Safe Learning Practices

- Practice destructive commands in a test directory or disposable environment.
- Review commands carefully before using `sudo`.
- Never expose passwords, SSH private keys, AWS credentials, or access tokens.
- Do not commit secret files to GitHub.
- Use least-privilege access for users, roles, and services.
- Verify cloud resources and costs before and after practical exercises.
- Understand a command before running it on a production system.
- Keep backups before changing important configuration files.
