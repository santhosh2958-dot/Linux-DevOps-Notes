## 🧪 My Daily Practice Method

1. Learn one new concept.
2. Understand the command and all important options.
3. Practice on an AWS EC2 Linux instance.
4. Record the syntax and expected output.
5. Document errors and troubleshooting.
6. Add the notes to the appropriate GitHub folder.
7. Revise previous commands.
8. Practice interview questions.

## 📝 Notes Format

Every topic should include:

- **Definition:** What is it?
- **Purpose:** Why is it used?
- **Syntax:** How do I use it?
- **Options:** Important command flags
- **Examples:** Basic to advanced
- **Hands-on:** AWS EC2 practical exercises
- **Expected Output:** How to verify
- **Troubleshooting:** Common errors
- **Interview Questions:** Questions and answers
- **Quick Revision:** Important points to remember
